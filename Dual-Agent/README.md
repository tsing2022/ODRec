# Agent materials

`questionnaire.json` contains the fixed 60-item question bank and six answer options. `prompts.json` contains persona, Analyst and Reflector prompts.

The self questionnaire uses the observed profile; the partner questionnaire uses the generated partner persona. Items are answered separately and checked against the profile and accepted-answer history. These files document the inputs to the four externally prepared semantic representations. This evaluation release does not execute agent generation.
